# Stock Backend API 

This application serves as a backend server for the stock exchange app
link to the app: stock-exchange-app-git-main-shankarnarayan1555-3920s-projects.vercel.app

## Tech Stack 
- Spring Boot
- MongoDB Atlas

## API Endpoints 
- GET /player/{name}/name
- POST /player
- GET /company
- PUT /company/{id}/price
- PATCH /{id}/transaction
- PATCH /{id}/deleteTransaction/{transactionId}
